# Tap and Scrape Band

A little browser toy where a row of tapping and scraping instruments will play a rhythm together. I'm building it one step at a time.

Right now (step 2) every instrument has its own sound, made with the Web Audio API: a woodblock tock, claves clack, a guiro scrape, a triangle ting and a shaker shh.

To play, tap or click an instrument. It wiggles and glows when it sounds. Next I'll add looping patterns, step clicking and a tempo slider.
